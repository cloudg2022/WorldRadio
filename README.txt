WORLD RADIO — INSTALACIÓN

1. Extrae todos los archivos del ZIP.
2. Publícalos juntos en un alojamiento estático con HTTPS (por ejemplo, GitHub Pages, Netlify o Cloudflare Pages).
3. Abre la URL HTTPS en Samsung Internet.
4. Desde el menú del navegador, usa "Añadir página a" > "Pantalla de inicio" (el texto exacto puede variar).

No hace falta servidor de aplicaciones ni claves API. Se necesita Internet para consultar emisoras y escuchar audio. El service worker solo guarda los archivos de la interfaz, NO las emisiones.

Aviso: algunos servidores de streaming pueden no reproducirse en el navegador por restricciones HTTPS, codecs o geográficas. El catálogo es Radio Browser, no una lista exhaustiva de todas las radios existentes.
